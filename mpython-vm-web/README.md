# mPython VM Studio —— 双模式虚拟掌控板教学工作台

> 面向中小学编程教学的一体化虚拟掌控板仿真环境：内置编译器、双模式教学切换、真实传感器接入与本地 AI 代码改写辅助。

## 项目简介

mPython VM Studio 是一款运行在桌面端的**虚拟掌控板教学工作台**。它以传统 IDE 的朴素界面承载完整的"图形化编程 → 代码 → 硬件反馈"教学闭环，帮助学生在没有实体掌控板的情况下也能完成编程入门、传感器感知与硬件控制的完整学习。

项目提供两种互补的运行模式：

| 模式 | 适用场景 | 说明 |
| --- | --- | --- |
| **Mind+ 上传模式** | 图形化编程过渡 | 粘贴 Mind+ 自动生成代码，内置转译器自动转换为 Python 后直接运行到虚拟板 |
| **教学模式** | 课堂演示与练习 | 直接编写 mPython / PinPong 代码，PinPong 模式可调用本地 AI 辅助改写代码 |

## 核心功能

- **内置编译器与转译器**：Mind+ 图形化代码（`当启动时`、`重复执行`、`如果/否则`、OLED/RGB/传感器指令）自动转译为 Python 并编译执行，语法错误带行号与光标定位提示。
- **完整的虚拟掌控板硬件仿真**：OLED 屏、三路 RGB LED、双按键、六路触摸、蜂鸣器、加速度计、陀螺仪、磁力计、光线与声音传感器。
- **真实传感器连接**：通过 USB 串口连接真实掌控板（mPython 固件），实时读取并展示加速度、陀螺仪、磁力、光线、声音等真实传感器数据；支持端口自动检测、心跳断线检测与一键断开。
- **手动控制面板**：滑杆 / 数值输入 / 快捷预设三种方式精确调整每个传感器，支持三维向量传感器（加速度 / 陀螺仪 / 地磁）逐轴调节与三方向模拟晃动。
- **PinPong AI 改写**：接入本地 Ollama + DeepSeek 模型，把自然语言课堂要求转成结构化 PinPong 教学代码。
- **传统桌面 IDE 体验**：标准工具栏、快捷键（F5 运行 / F6 停止 / Ctrl+S 保存 / Ctrl+O 打开）、三栏紧凑布局、中英文界面切换。

## 快速开始

### 环境要求

- Python 3.10+
- Windows / macOS / Linux

### 安装与启动

```bash
pip install -r requirements.txt
python main.py
```

### 使用流程

1. 启动后选择模式：**Mind+ 上传模式** 或 **教学模式**（mPython / PinPong）。
2. 在编辑器输入代码（或点击"示例"加载内置示例）。
3. 点击 **运行（F5）**，右侧虚拟掌控板实时呈现 OLED / RGB / 按键 / 传感器反馈；**停止（F6）** 可随时中断运行中的代码。
4. Mind+ 模式下可先点击 **转译** 预览 Python 代码。

## 真实传感器连接指南

1. 用 mPython IDE / Thonny 将 [`tools/sensor_report.py`](tools/sensor_report.py) 上传到掌控板并运行（代码会持续上报传感器数据）。
2. 在 mPython VM Studio 的 **传感器 → 真实传感器** 页点击 **扫描**，从下拉框选择设备端口（或使用"自动检测"）。
3. 点击 **连接**，加速度、陀螺仪、磁力、光线、声音数据将实时刷新在右侧面板。

> 未连接设备时页面不显示任何模拟数值，确保展示的都是真实采集数据。

## 目录结构

```
mpython-vm-web/
├── main.py                  # 桌面应用入口（pywebview）
├── requirements.txt         # 项目依赖
├── backend/
│   ├── api.py               # 前后端桥接 API
│   ├── simulator.py         # 仿真器核心调度
│   ├── hardware.py          # 硬件状态模型
│   ├── code_executor.py     # 代码执行器（可中断 sleep / 语法错误定位）
│   ├── transpiler.py        # Mind+ 图形化代码 → Python 转译器
│   ├── sensor_device.py     # 真实传感器串口连接管理
│   └── ollama_helper.py     # 本地 Ollama / DeepSeek AI 改写
├── frontend/
│   ├── index.html           # 主界面
│   ├── css/style.css        # 桌面风格样式
│   ├── js/app.js            # 前端逻辑（Vue 3）
│   ├── examples/            # 内置示例代码
│   └── vendor/              # 本地化 Vue / Monaco（离线可用）
└── tools/
    └── sensor_report.py     # 掌控板端传感器上报脚本（MicroPython）
```

## 技术栈

- **桌面壳**：pywebview（WebView 桥接）
- **前端**：Vue 3 + Monaco Editor（均已本地化，完全离线可用）
- **仿真内核**：Python 线程模型 + `sys.settrace` 指令级停止控制
- **转译器**：Mind+ 图形化代码规则转换（正则 + 缩进层级计算）
- **AI 辅助**：Ollama + DeepSeek（本地推理，数据不出本机）
- **硬件通信**：pyserial 串口 JSON 上报协议

## 教学应用场景

- **图形化 → 代码过渡课**：学生先用 Mind+ 图形化编程，观察转译后的 Python 代码，理解抽象概念。
- **传感器认知课**：连接真实掌控板或使用手动控制，直观理解加速度、光线、声音传感器的数值变化。
- **代码改写训练课**：PinPong 模式下让学生编写原始代码，再用 AI 改写为更规范的教学版本，对比学习。
- **无硬件演示课**：没有实体掌控板时，虚拟板提供完全一致的教学体验。
