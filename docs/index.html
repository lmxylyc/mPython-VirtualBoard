一套工具，覆盖教学全链路

从图形化启蒙到代码进阶，从虚拟仿真到真实传感器，一个平台全部搞定。

完整硬件仿真

OLED 屏、三路 RGB、双按键、六路触摸、蜂鸣器，以及加速度、陀螺仪、磁力、光线、声音传感器，一应俱全。

双编程模式

mPython 与 PinPong 两条教学路径自由切换，贴合不同教材与课程体系。

Mind+ 图形化转译

粘贴 Mind+ 上传模式自动生成的代码，内置转译器一键转为 Python 并直接运行，平滑完成图形化到代码的过渡。

本地 AI 辅助改写

PinPong 模式接入本地 Ollama + DeepSeek 模型，把自然语言课堂要求改写成规范教学代码，数据不出本机。

真实传感器接入

通过 USB 串口连接实体掌控板，实时读取真实加速度、陀螺仪、磁力、光线与声音数据，虚实验证两不误。

Thonny 联动与悬浮窗

桌面版可与 Thonny / IDLE 无缝配合，虚拟板窗口始终置顶悬浮，边写代码边看效果。

两个版本，各取所需

同一颗仿真内核，两种产品形态，覆盖不同教学习惯。
